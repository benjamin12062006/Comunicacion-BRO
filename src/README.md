# Código fuente de Comunicacion-BRO

- `pages/`: rutas Astro originales.
- `layouts/`: documento y estructura original.
- `components/`: componentes Astro originales.
- `styles/`: Tailwind y tokens visuales originales.
- `islands/AuthIsland.vue`: componente Vue mínimo que muestra `Hello World`. Conserva su nombre para mantener intacta la página Astro que lo importa.
- `env.d.ts`: tipos de Astro.

La base conserva la presentación de Navigate; la lógica de autenticación fue retirada.
